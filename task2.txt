1. Program starts: 
                  Saves the current screen contents into a 4000-byte buffer.
2. First key press: 
                  int 16h waits for a keyboard input.
3. Screen clears: 
                 clrscr clears the entire screen.
4. Second key press: 
                    Program waits while the screen remains blank.
5. Screen restores: 
                   restoreScreen copies the saved contents back to video memory.
6. Third key press: 
                   Program waits for another keyboard input.
7. Program terminates:
                      int 21h, ah=4ch exits the program.
